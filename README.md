## Customer Support Ticket System

A responsive customer support ticket management system built with React.
Users can view and manage customer tickets, track ticket status, complete
tasks, and monitor resolved issues through an interactive dashboard.

### Technologies Used

- React
- JavaScript
- HTML
- CSS
- Tailwind CSS
- React Icons
- React Toastify

### Features

- Customer ticket management
- Track In-Progress and Resolved tickets
- Complete support tasks
- Resolved task tracking
- Priority and status indicators
- Toast notifications
- Responsive dashboard
